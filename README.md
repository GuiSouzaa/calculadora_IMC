# 🧮 Calculadora de IMC

Este projeto é um app Android desenvolvido em **Java** com o objetivo de calcular o **Índice de Massa Corporal (IMC)** com base no peso e altura fornecidos pelo usuário.

---

## 📲 Funcionalidades

- Entrada de peso (kg) e altura (m);
- Cálculo do IMC automático ao clicar no botão "Calcular";
- Exibição da faixa de classificação do IMC (ex: Abaixo do peso, Normal, Sobrepeso, Obesidade, etc.);
- Interface simples e funcional;
- Estilo visual com bordas e espaçamento ajustados.
